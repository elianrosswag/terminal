How it works

This site's server reads your Revolut X account with a read-only API key and signs each request with your private key. Both live only in Netlify's environment variables (REVX_API_KEY, REVX_PRIVATE_KEY). The access token (TERMINAL_TOKEN) stops anyone else using it; it's the one line in _private-revolut-x/terminal-access-token.txt.

Revolut statements

Stocks & crypto in the main Revolut app
Import a statement

Revolut has no API for app investments, so import its CSV statements instead. In the Revolut app: Invest → More → Documents → Stocks (or Crypto) → account statement → CSV, for the whole period you've held them. Each import replaces the previous one of the same kind.
