Setup
  1. exchange.revolut.com → Profile → API keys: create a read-only key with the public key from _private-revolut-x/public.pem. No IP whitelist.
  2. Netlify → this project → Environment variables (scope Functions): REVX_API_KEY, REVX_PRIVATE_KEY (the whole private.pem), TERMINAL_TOKEN. Then redeploy.
  3. Paste the same TERMINAL_TOKEN into the box on the left. It's stored only in this browser.

Your balances and orders are fetched by this site's server with your key and are never cached or stored anywhere but this browser.
